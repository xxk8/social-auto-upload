# AI 助手面板 UI 重构调研

> 本文档对比 ChatGPT、Claude、Gemini、Cursor 等主流 AI 工具的设计模式，分析当前 Web Shell AI 面板的问题，并提出重构方向。

---

## 1. 当前问题分析

### 现有布局（PublishPage 两栏）

```
┌─────────────────────────┬──────────────────────────────────┐
│  发布中心（Wizard）       │  AI 助手面板                       │
│                         │                                  │
│  [平台选择器]            │  ┃ [Sparkles] AI 助手 · model · ⚙ │
│  [步骤指示器]            │  ┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ┃
│  [上传/内容/预览]        │  ┃  聊天消息区域                    │
│  [导航按钮]             │  ┃                                │
│                         │  ┃  ┌─ InlineMagicBar ──────────┐ │
│                         │  ┃  │ 一键生成 多平台变体 优化表达  │ │
│                         │  ┃  │ 应用上次 清空               │ │
│                         │  ┃  └───────────────────────────┘ │
│                         │  ┃  ┌─ MaterialSection ─────────┐ │
│                         │  ┃  │ ▼ 图片素材 Pexels·Pixabay  │ │
│                         │  ┃  │   [搜索框] [3×3 网格]      │ │
│                         │  ┃  │ ▼ 链接拉取 yt-dlp+browser  │ │
│                         │  ┃  │   [URL 输入] [拉取按钮]    │ │
│                         │  ┃  └───────────────────────────┘ │
│                         │  ┃  [textarea]           [发送]  │
│                         │  ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ┃
└─────────────────────────┴──────────────────────────────────┘
```

### 核心问题

| 问题 | 描述 | 对标竞品 |
|------|------|----------|
| **Header 过重** | 品牌 + 模型名 + 状态点 + 模型选择器 + 设置按钮 + 折叠按钮，6 个元素挤在一行 | ChatGPT 只有模型下拉；Claude 只有简洁 header |
| **工具栏常驻** | InlineMagicBar 5 个按钮始终显示，即使用户不需要 | ChatGPT 空状态才显示建议；Claude 无常驻工具栏 |
| **MaterialSection 层级乱** | 图片素材 + 链接拉取两个 Accordion，展开后占 380px/240px，标题带 "Pexels · Pixabay"、"yt-dlp + browser" 技术细节 | ChatGPT 附件只是一个 📎 图标 |
| **信息密度高** | 每个区域都有独立的标题、描述、技术标签，视觉噪音大 | ChatGPT 界面几乎无文字标签 |

## 2. 竞品设计模式

### 2.1 联网搜索

| 工具 | 交互方式 | 默认状态 | 设计要点 |
|------|----------|----------|----------|
| **ChatGPT** | 输入框左侧 🌐 地球图标 | 半自动（AI 判断 + 手动触发） | 图标常驻但低调，点击切换 |
| **Claude** | "+" 按钮菜单 → Web search | 按需开启（Toggle） | 折叠在二级菜单 |
| **Gemini** | 内置 | 始终启用 | 无需用户操作 |
| **Cursor** | `@` 符号引用 | 上下文自动 | 符号驱动 |

**最佳实践**：ChatGPT 的地球图标 — 一个小按钮，不占空间，需要时点击。

### 2.2 文件上传

| 工具 | 主要入口 | 额外方式 | 设计要点 |
|------|----------|----------|----------|
| **ChatGPT** | 📎 回形针图标 | 拖拽、粘贴 | 输入框底部工具栏 |
| **Claude** | "+" 按钮 | 拖拽、粘贴 | 二级菜单 |
| **Cursor** | `@` 符号引用 | 自动索引 | 上下文引用而非上传 |

**最佳实践**：ChatGPT 的 📎 — 用户一看就懂，点击即上传。

### 2.3 模型选择

| 工具 | 位置 | 显示方式 |
|------|------|----------|
| **ChatGPT** | 顶部标题栏 | 下拉选择器 |
| **Claude** | 左下角/设置 | 下拉选择器 |
| **Cursor** | 输入框右侧 | 内联下拉 + "Suggested" 标签 |

**最佳实践**：Cursor 的输入框右侧内联选择器 — 随时可见但不抢焦点。

### 2.4 快捷指令

| 工具 | 入口 | 展示方式 |
|------|------|----------|
| **ChatGPT** | 空状态建议 + Canvas 工具栏 | 卡片滚动 + 按钮菜单 |
| **Claude** | Projects / Skills | 功能入口 |
| **Cursor** | `/` 命令 | 命令列表 |

**最佳实践**：ChatGPT 的空状态卡片 — 友好引导，用完即消失。

### 2.5 工具栏

| 工具 | 位置 | 内容 |
|------|------|------|
| **ChatGPT** | Canvas 右侧垂直 + 底部水平 | 写作/代码快捷操作 + 附件/搜索 |
| **Claude** | 左下角入口 | 附件、功能菜单 |
| **Cursor** | 输入框内 | `/` 命令 + `@` 引用 |

**最佳实践**：ChatGPT 底部水平工具栏 — 附件、搜索、语音并排，图标化。

### 2.6 空状态

| 工具 | 显示内容 | 设计模式 |
|------|----------|----------|
| **ChatGPT** | "Ready when you are." + 建议卡片 | 友好问候 + 引导性建议 |
| **Claude** | 简洁输入界面 | 等待用户输入 |
| **Cursor** | 项目文件浏览器 + 输入框 | 以项目为中心 |

**最佳实践**：ChatGPT 的引导式卡片 — 降低新用户使用门槛。

---

## 3. 设计趋势总结

1. **搜索功能**：从"手动搜索"→"AI 自动判断 + 手动触发"
2. **文件上传**：统一 "+" 或 📎 图标，支持拖拽和粘贴
3. **模型选择**：放在显眼位置（顶部或输入框旁），支持随时切换
4. **快捷指令**：空状态卡片式建议 + `/` 命令系统
5. **工具栏**：趋向内联化和上下文化，减少界面层级
6. **空状态**：引导式建议卡片是提升新用户转化的关键

## 4. 重构建议

### 4.1 精简 Header

**Before**: `✨ AI 助手 · gpt-4o · ● · [模型选择] · [⚙] · [×]`

**After**: 只保留模型选择器下拉，其他藏起来

```
┌──────────────────────────────────────┐
│  ✨ AI 助手    [gpt-4o ▾]      [×]  │
└──────────────────────────────────────┘
```

- 模型选择：内联下拉（参考 Cursor）
- 设置按钮：移到模型下拉菜单内
- 状态点：去掉或仅在未配置时显示

### 4.2 重新设计 Composer 工具栏

参考 ChatGPT 底部工具栏，把功能图标化：

```
┌──────────────────────────────────────────────────┐
│  [🌐] [📎] [🖼️] [🔗]   [textarea...]    [发送]  │
│  联网   附件  素材  链接                           │
└──────────────────────────────────────────────────┘
```

| 图标 | 功能 | 说明 |
|------|------|------|
| 🌐 | 联网搜索 Toggle | 点击切换开/关 |
| 📎 | 文件上传 | 点击选择文件 |
| 🖼️ | 图片素材 | 点击展开搜索面板（Popover） |
| 🔗 | 链接拉取 | 点击展开 URL 输入（Popover） |

**关键改变**：
- 移除 InlineMagicBar（5 个常驻按钮）
- 移除 MaterialSection（2 个 Accordion）
- 功能全部收进图标，Popover 按需展开

### 4.3 简化空状态

参考 ChatGPT 的引导式卡片：

```
┌──────────────────────────────────────┐
│                                      │
│         ✨ 选一个动作开始              │
│                                      │
│  ┌─────────────┐ ┌─────────────┐    │
│  │ ⚡ 一键全流程 │ │ 🎨 多平台变体 │    │
│  │ 增强→生成→应用│ │ 各平台并行生成│    │
│  └─────────────┘ └─────────────┘    │
│  ┌─────────────┐ ┌─────────────┐    │
│  │ ✏️ 优化表达  │ │ 💬 自由对话  │    │
│  │ 只跑提示词优化│ │ 聊天式打磨   │    │
│  └─────────────┘ └─────────────┘    │
│                                      │
│  ──────────────────────────────────  │
│  [🌐] [📎] [🖼️] [🔗]    [输入...]  [发送] │
└──────────────────────────────────────┘
```

- 空状态：4 个建议卡片（已有，保持）
- 有消息后：卡片消失，聊天区域接管

### 4.4 MaterialSection 重构

**Before**: 两个 Accordion 常驻显示，标题带技术标签

**After**: 两个图标按钮，Popover 按需展开

```
Before:
┌─────────────────────────────┐
│ ▼ 📷 图片素材 Pexels·Pixabay │
│   [搜索] [3×3 网格]         │
│ ▼ 🔗 链接拉取 yt-dlp+browser │
│   [URL 输入] [拉取]          │
└─────────────────────────────┘

After:
[🖼️] → Popover: 图片搜索面板
[🔗] → Popover: 链接拉取面板
```

- 移除 "Pexels · Pixabay"、"yt-dlp + browser" 等技术标签
- 用图标代替文字标题
- Popover 按需展开，不占主界面空间

### 4.5 快捷命令系统

参考 Cursor 的 `/` 命令：

```
用户输入: /

┌─────────────────────────────────┐
│  /fullflow  一键全流程           │
│  /variants  多平台变体           │
│  /enhance   优化表达             │
│  /apply     应用上次结果         │
│  /clear     清空会话             │
└─────────────────────────────────┘
```

- 输入 `/` 弹出命令列表
- 移除 InlineMagicBar 的 5 个常驻按钮
- 命令可通过键盘快速选择

## 5. 重构优先级

| 优先级 | 改动 | 预期效果 | 复杂度 |
|--------|------|----------|--------|
| **P0** | 精简 Header（模型选择器下拉） | 减少 header 视觉重量 | 低 |
| **P0** | MaterialSection 改为图标 Popover | 释放 380px+ 空间 | 中 |
| **P0** | 移除 InlineMagicBar 常驻显示 | 减少视觉噪音 | 低 |
| **P1** | Composer 工具栏图标化 | 统一交互模式 | 中 |
| **P1** | `/` 命令系统 | 替代 InlineMagicBar | 中 |
| **P2** | 空状态卡片优化 | 提升引导体验 | 低 |
