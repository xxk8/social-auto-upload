## 1. 背景与目标

### 1.1 问题

当前任务管理是**列表视图**，只能看到任务的状态和时间，无法直观了解：

- 这周每天分别要发什么内容？
- 哪些天排期过密，哪些天是空的？
- 某个平台的发布节奏是否均匀？

对于需要提前一周甚至一个月排期的运营者来说，列表视图缺乏**时间维度的全局视角**。

### 1.2 目标

提供**日历视图**，让运营者能够：

| 能力 | 说明 |
|---|---|
| 可视化排期 | 一眼看到每天有哪些任务 |
| 拖拽调整 | 直接拖动任务到其他日期 |
| 快速创建 | 点击日期空白处直接新建任务 |
| 平台筛选 | 按平台/账号过滤显示 |
| 周/月切换 | 灵活查看不同时间范围 |

---

## 2. 用户故事

### 2.1 核心用户：内容运营者

```
作为内容运营者，我想要：
├─ 在日历上看到所有排期 → 掌握全局节奏
├─ 拖拽调整发布时间 → 灵活应对变化
├─ 按平台筛选 → 只看特定平台的排期
├─ 快速创建任务 → 点击日期直接添加
└─ 查看空闲日期 → 发现发布空白期
```

### 2.2 使用场景

| 场景 | 频率 | 需要的信息 |
|---|---|---|
| 周计划制定 | 每周 | 本周每天的发布安排 |
| 排期调整 | 随时 | 某天的任务是否可以挪到其他天 |
| 空白期发现 | 每周 | 哪些天没有内容发布 |
| 多平台协调 | 每天 | 同一内容在不同平台的发布时间 |
| 月度复盘 | 每月 | 上月发布密度和分布 |

### 3.6 数据库支持

日历视图复用现有 `tasks` 表，通过 `created` 和 `schedule` 字段查询：

```sql
-- 获取某月所有任务
SELECT task_id, platform, account, title, status, 
       created, schedule, action
FROM tasks
WHERE created >= '2026-07-01' 
  AND created < '2026-08-01'
ORDER BY COALESCE(schedule, created);

-- 按平台筛选
SELECT ... FROM tasks
WHERE platform IN ('douyin', 'bilibili')
  AND created >= :start AND created < :end;
```

### 3.7 API 设计

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/calendar/tasks` | 获取日历范围内的任务 |
| PUT | `/api/calendar/tasks/{id}/reschedule` | 修改任务发布时间（拖拽） |

#### 日历查询参数

```
GET /api/calendar/tasks?start=2026-07-01&end=2026-07-31&platform=douyin&account=work1
```

### 3.8 前端技术选型

| 方案 | 优点 | 缺点 | 推荐 |
|---|---|---|---|
| **自研轻量日历** | 无依赖、完全可控 | 开发量大 | ❌ |
| **react-big-calendar** | 成熟、支持拖拽 | 体积较大 | ✅ 首选 |
| **@fullcalendar/react** | 功能丰富、视图多 | 商业授权（GPL） | ⚠️ 需确认 |
| **tui-calendar** | 轻量、韩系设计 | 维护不活跃 | ❌ |

推荐使用 `react-big-calendar`，MIT 协议，支持自定义渲染和拖拽。

### 3.9 实现优先级

| 阶段 | 内容 | 预估工作量 |
|---|---|---|
| P0 | 月视图 + 任务显示 + 平台颜色编码 | 2 天 |
| P1 | 周视图 + 点击展开详情 | 1.5 天 |
| P2 | 拖拽调整时间 + 快速创建 | 2 天 |
| P3 | 平台/账号筛选 + 统计摘要 | 1 天 |

## 4. 技术要点

### 4.1 平台颜色映射

```typescript
const PLATFORM_COLORS: Record<string, string> = {
  douyin:    '#00f2ea',  // 抖音蓝
  bilibili:  '#fb7299',  // B站粉
  xiaohongshu: '#ff2442', // 小红书红
  kuaishou:  '#ff4906',  // 快手橙
  tencent:   '#07c160',  // 视频号绿
  baijiahao: '#2932e1',  // 百家号蓝
  tiktok:    '#010101',  // TikTok黑
  youtube:   '#ff0000',  // YouTube红
};
```

### 4.2 拖拽实现

- `react-big-calendar` 内置 `Draggable` 支持
- 拖拽完成后调用 `PUT /api/calendar/tasks/{id}/reschedule`
- 更新数据库中的 `schedule` 字段
- 如果任务已执行，禁止拖拽（灰色不可拖）

### 4.3 性能优化

- 月视图只加载当前月的任务（后端分页）
- 周视图加载前后各一周作为缓冲
- 使用虚拟滚动处理大量任务块
- 任务块按时间排序，避免重叠渲染

### 4.4 与现有功能集成

- 从日历点击「新建」→ 打开现有的「添加任务」对话框，预填日期
- 从日历点击任务 → 打开现有的「任务详情」抽屉
- 日历和任务列表共享同一数据源，切换视图不丢失状态
